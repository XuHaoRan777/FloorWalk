# FloorWalk

连锁门店巡检系统。店员按清单现场拍照，主管审核，总部看门店得分。

这是三端作品样本，不是支付产品，也不是 CardFlow 换皮。当前已建立 API、Web、Mobile 与 shared 工程骨架，并完成巡检主链契约和 Northbean 演示种子。当前能力见 [工程骨架规格](docs/specs/workspace.md) 与 [巡检主链规格](docs/specs/inspection.md)。
