# Web 控制台

代码（归档时再生成）：`apps/web/src/`

## 主管审核

主管登录后进入审核队列。队列列出待审核和审核中的巡检，显示门店、提交时间、分数和状态。打开尚未开始审核的巡检时，页面自动开始审核。详情展示检查结果、备注、照片和审核历史。

主管可以通过、判不合格或打回巡检。打回至少选择一个检查项，可填写意见；存在严重项不合格时不能通过。操作成功后页面显示 API 返回的新状态。

## 总部看板

总部登录后查看各门店最近判定巡检的分数与状态，可打开审核队列和详情，但没有审核操作按钮。店员登录 Web 时会看到使用手机端的提示，不进入控制台。

## 错误处理

网络错误和 API 错误以中文提示。会话失效时返回登录页。

## 没有的

没有用户、门店和模板管理页，也没有聊天或 Web Demo 内容页。Web 将 Bearer Token 保存在 `localStorage`，因此同源脚本发生 XSS 时可读取有效 Token；改为 HttpOnly 会话需要调整认证契约，已登记为第二组待开单元。
