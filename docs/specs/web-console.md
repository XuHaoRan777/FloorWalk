# Web 控制台

代码（归档时再生成）：`apps/web/src/`；认证页共用框架位于 `components/layout/auth-frame.tsx`

## 审核

商家管理员登录后进入任务审核队列。队列按任务分组显示待人工审核条目和当天已判定任务，并展示门店、模板、提交时间、理由、分数与整单结论；打开任务后逐条查看检查结果、自评、照片、提交人昵称和上传时间。控制台顶栏显示待我处理数量。

商家管理员可逐条判通过、打回或不合格；截止后的 1 小时宽限期内可打回，之后只能判通过或不合格。判定后仍可逐条改判，页面显示最新条目结论、重算后的分数与整单结论；每次改判保留操作人、时间和前后结论审计记录。详情可查看[巡检单聊天](chat.md)，聊天发送权限仅限本店店长。

审核详情页头常驻显示逐项结果 R2 分段环和当前分数。已判定任务打开或刷新时静态显示，当前通过弧为品牌蓝，当前不合格弧为红色，待判和仍属系统缺交的条目留空轨道。缺交后的人工改判按当前结论着色，并保留截止时缺交标记。管理员本次操作成功令任务首次获得 `decidedAt` 时播放一次，改判成功也播放一次；播放中再次改判则直接显示新终态。审核队列总览为空时使用通知点阵插画。

## 商家管理员看板

商家管理员可查看各门店最近判定巡检的分数与状态，停用门店标「已停用」并保留最近分数；也可进入任务审核队列并逐条判定。今日视图列出各店当天任务、时间窗、状态和分数，汇总应完成、已完成及逾期数量，并列出严重项不合格或逾期任务和待人工处理项；没有任务时显示「今日无任务」。

今日视图和总部看板主视图无数据时复用空平面插画，现有空态文字和操作保持不变。

商家管理员看板支持本周或本月周期，并可按门店、店长或日期趋势查看完成率（截止前交齐任务数 ÷ 应完成任务数）、逾期数、自检准确率和已判定任务平均分。店长维度显示提交条目数、通过率和自检准确率；空数据时显示空状态而不绘制空图表。店长登录 Web 时会看到使用手机端的提示，不进入控制台。

## 门店与模板

商家管理员可在侧栏进入门店与模板页，进行[门店与模板管理](admin.md)；也可进入[日程方案与门店安排](schedules.md)管理每周任务列表、门店选用和跳过日期区间。操作后列表显示 API 返回的内容与状态。

门店、模板、AI 审核标准和日程方案列表的主空态复用清单加号插画；账号空态和局部空项不配插画。

## 站内通知

商家管理员可从控制台顶栏通知入口查看未读数量和最近 20 条通知。选择通知后系统标记已读并导航到对应巡检、条目或聊天位置；事件和接收人见[站内通知](notifications.md)。

## 错误处理

网络错误和 API 错误以中文提示。会话失效时返回登录页。

## 注册与账号

首页提供商家注册入口；验证邮箱后创建商家及首个管理员并直接进入该商家的控制台。管理员可在人员管理页查看账号、新建店长、重置密码、停用和启用账号，也可调店。管理员和店长是商家内仅有的两种角色；首次登录跳转强制改密页，成功后进入原首页。登录名与密码跨商家匹配多个启用账号时，登录流程让用户选择商家。登录页提供邮箱验证码找回密码。会话只存在 HttpOnly cookie，页面首次加载通过 `/api/me` 判断会话；不支持跨站点部署。生产构建与 preview 带 CSP，开发服务器不添加 CSP。

登录、注册、找回管理员密码和强制改密共用 H5 蓝底平面与巡检单主视觉及 C1 文案，主视觉打开后仅播一次并停在终态。侧栏、浏览器 favicon 与四个认证表单头使用 L1「F 字动线」标志。

管理员可从侧栏左下角的头像和昵称菜单进入账户设置或退出登录。账户设置可更新昵称、查看头像和账号资料、改密码；登录名只读。头像与店长账号使用同一头像上传规则。账户菜单在点击外部区域或按 Escape 时关闭，Escape 关闭后焦点返回触发器。管理员侧栏按巡检工作、管理配置排列，入口依次为今日视图、总部看板、审核队列、门店、模板、门店日程安排、日程方案、AI 审核标准和人员管理。功能页通用次级按钮、任务查看入口和信息提示等非结果语义强调使用品牌蓝；青绿色用于点亮与成功语义。

## 窄屏布局

控制台顶栏固定在视口内，功能页内容仅在主内容区纵向滚动，页面本身不随功能内容滚动。

Web 控制台视口宽度小于 1024px 时，侧栏通过抽屉打开，抽屉打开后焦点进入其中，关闭按钮或 Esc 可关闭，焦点返回侧栏触发器。1024px 及以上沿用桌面侧栏。登录用户头像与昵称位于侧栏底部，点击后可进入账户设置或退出登录；顶栏保留通知与待处理入口。审核详情内容最大宽度为 1680px 并居中，避免超宽屏上信息分散；320px 及以上无页面级横向滚动，极窄屏待处理计数改为图标按钮并保留可访问名称。宽表格只在自身区域横向滚动。768～1023px 下，看板门店、店长排行榜和日期趋势无需横滚，人员列表可横滚且首列固定。表格字段保持不变。768、1024、1440px 下，今日视图指标为窄屏双列、宽屏三列，审核队列任务行在窄屏分层显示，审核详情在 1440px 并排显示检查项和只读聊天，在 1024px 及以下上下排列；审核详情页头在窄屏将任务信息与状态/圆环摘要分开排列，圆环显示尺寸为 144px。门店与人员表格在自身区域横向滚动，通知收件箱保留为顶栏打开的 Sheet，七页均无页面级横向滚动。门店、人员和审核状态同时以文字及语义色表达，长文本在内容区域内换行。AI 审核标准页和日程方案页均按“标题、操作、列表、编辑区”组织，列表在编辑区上方，窄屏保持单列，长名称可换行。门店日程安排页将刷新、已选门店数和批量操作置于门店表前，两组批量表单在 768px 和 1024px 纵向排列，门店表可在自身区域横向滚动。认证页登录、注册、找回管理员密码和强制改密共用单栏认证框架，不使用控制台侧栏；根级 404 保留独立外框。上述页面在 768px、1024px、1440px 均无页面级横向滚动，状态文字同时使用语义色表达。控制台侧栏不显示无效的“返回登录”入口。
