# Web 控制台

代码（归档时再生成）：`apps/web/src/`

## 审核

主管或商家管理员登录后进入审核队列。队列列出待审核和审核中的巡检，显示门店、提交时间、分数和状态。打开尚未开始审核的巡检时，页面自动开始审核。详情展示检查结果、备注、照片和审核历史。

主管和商家管理员可以通过、判不合格或打回巡检。打回至少选择一个检查项，可填写意见；存在严重项不合格时不能通过。操作成功后页面显示 API 返回的新状态。详情可收发[巡检单聊天](chat.md)。

## 商家管理员看板

商家管理员登录后查看各门店最近判定巡检的分数与状态，停用门店标「已停用」并保留最近分数；也可进入审核队列并执行审核。店员登录 Web 时会看到使用手机端的提示，不进入控制台。

## 门店与模板

商家管理员和主管可在侧栏进入门店与模板页，进行[门店与模板管理](admin.md)。操作后列表显示 API 返回的内容与状态。

## 错误处理

网络错误和 API 错误以中文提示。会话失效时返回登录页。

## 没有的

首页提供商家注册入口；注册成功后创建商家管理员并直接进入该商家的控制台。账号页支持本商家账号列表、新建员工、重置密码、停用和启用；主管仅管理名下店员。首次登录跳转强制改密页，成功后进入原首页。会话只存在 HttpOnly cookie，页面首次加载通过 `/api/me` 判断会话；不支持跨站点部署。生产构建与 preview 带 CSP，开发服务器不添加 CSP。
