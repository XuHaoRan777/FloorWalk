# Web 控制台

代码（归档时再生成）：`apps/web/src/`

## 审核

商家管理员登录后进入任务审核队列。队列按任务展示门店、日期、时间窗、任务状态、巡检分数与整单结论；打开任务后逐条查看检查结果、自评、照片、提交人昵称和上传时间。

管理员可逐条判通过、打回或不合格；截止后的 1 小时宽限期内可打回，之后只能判通过或不合格。判定后仍可逐条改判，页面显示最新条目结论、重算后的分数与整单结论；每次改判保留操作人、时间和前后结论审计记录。详情可收发[巡检单聊天](chat.md)。

## 商家管理员看板

商家管理员登录后查看各门店最近判定巡检的分数与状态，停用门店标「已停用」并保留最近分数；也可进入任务审核队列并逐条判定。店长登录 Web 时会看到使用手机端的提示，不进入控制台。

## 门店与模板

商家管理员可在侧栏进入门店与模板页，进行[门店与模板管理](admin.md)；也可进入[日程方案与门店安排](schedules.md)管理每周任务列表、门店选用和跳过日期区间。操作后列表显示 API 返回的内容与状态。

## 错误处理

网络错误和 API 错误以中文提示。会话失效时返回登录页。

## 没有的

首页提供商家注册入口；注册成功后创建商家管理员并直接进入该商家的控制台。账号页支持本商家账号列表、新建员工、重置密码、停用和启用；主管仅管理名下店员。首次登录跳转强制改密页，成功后进入原首页。会话只存在 HttpOnly cookie，页面首次加载通过 `/api/me` 判断会话；不支持跨站点部署。生产构建与 preview 带 CSP，开发服务器不添加 CSP。
