# Mobile 管理端

代码：[管理端路由](<../../apps/mobile/app/(authenticated)/admin/>)、[管理端组件](../../apps/mobile/components/mobile/admin/)、[通知收件箱](../../apps/mobile/components/mobile/notification-inbox-screen.tsx)、[API 客户端](../../apps/mobile/lib/api/)。

## 入口与配置

管理员登录及首次改密后进入 `/admin/today`。管理员底部 Tab 依次为「今日、审核、管理、我的」，个人资料固定末项；总部看板从「今日」页的「总部看板」入口打开，路由仍为 `/admin/dashboard`，Android 返回回到打开前的「今日」页。店长无法进入管理页面。管理员首页使用固定品牌行和通知入口，日期与页面标题随正文滚动；今日页按门店汇总任务进度，门店任务和待人工项均可进入审核详情。`/admin` 是 Web「管理配置」分组对应的配置首页，入口为人员管理、门店、模板、AI 审核标准、日程方案和门店日程安排。会话、账号与权限规则见[巡检主链](inspection.md)。

Mobile 复用[门店与模板管理](admin.md)和[日程方案与门店安排](schedules.md)的接口与规则：账号支持创建店长、改昵称、调店、停启和重置密码；门店支持创建、改名、停启和查看店长；模板支持检查项与 AI 配置、三套快捷配置；AI 标准支持增改删；日程支持七天任务与跨日时间窗，门店安排支持批量选方案和跳过日期区间。

表单适配手机屏幕，原生输入、选择和日期时间控件用于编辑；保存成功后更新列表，保存失败保留草稿。模板编辑的单一页面标题在滚动正文首部，底部取消与保存操作固定在导航栏上方。其他配置页标题和返回入口也在正文内，不叠加全局固定顶栏。刷新不覆盖随后保存的新值。配置在重新打开应用后保留。管理端视觉和交互状态见[Mobile 视觉与交互规范](../context/mobile-design.md)。

## 审核与看板

审核队列按任务显示待人工条目和当天已判定任务，卡片展示任务状态、提交或判定时间、分数及人工判定条目。任务详情展示条目照片、AI 理由、上传人、上传时间和当前结论；管理员可逐条判定或改判，结果刷新任务分数。判定操作固定在屏幕底部，按钮遵循 Mobile 内容宽度布局。今日视图按门店分组显示任务进度、汇总、严重项不合格及逾期提示和待人工项，不显示「AI 审核中」。总部看板支持周/月切换和门店、店长、日期趋势维度，展示完成率、逾期数、自检准确率及分数。

## 我的与通知

「我的」显示头像、昵称、登录名和角色；登录名只读，管理员可编辑昵称。管理员与店长均可上传头像、改密码和退出。通知入口打开按未读、已读分组的收件箱，支持刷新、分页、跳转和标记已读；无通知时显示空状态，管理员从通知进入审核详情后返回通知收件箱。主页角标最多显示 `99+`，应用回到前台刷新未读数。通知规则见[站内通知](notifications.md)。

## 没有的

管理员今日接口不提供门店照片和店长姓名，页面不展示这两项。看板现有数据不包含今日概况，Mobile 看板不为此增加取数。

## 数据契约（归档时再生成）

复用 Web 管理、本人资料和通知 API，不新增端点或共享字段。管理员导航入口为 [`管理端 Tabs`](<../../apps/mobile/app/(authenticated)/admin/_layout.tsx>)，今日看板入口由 [`管理员今日页`](../../apps/mobile/components/mobile/admin/admin-today-screen.tsx)呈现；审核由[`审核队列`](../../apps/mobile/components/mobile/admin/review-queue-screen.tsx)、[`审核详情`](../../apps/mobile/components/mobile/admin/review-detail-screen.tsx)和[`审核条目`](../../apps/mobile/components/mobile/admin/review-item.tsx)呈现。管理配置、本人资料和通知仍位于管理端路由、组件与 API 客户端目录。
