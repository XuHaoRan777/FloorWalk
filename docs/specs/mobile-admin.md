# Mobile 管理端

代码（归档时再生成）：`apps/mobile/components/mobile/admin/`、`apps/mobile/components/mobile/notification-inbox-screen.tsx`、`apps/mobile/app/(authenticated)/admin/`、`apps/mobile/lib/api/`

## 入口与配置

管理员登录后进入管理员主页，首次改密仍先完成改密；店长使用今日待巡、记录与我的。管理员主页提供今日视图、审核队列、总部看板、账号、门店、模板、AI 标准、日程、门店日程安排和本人资料入口；店长无法进入管理页面。管理员主页也显示通知入口与未读数。会话、账号与权限规则见[巡检主链](inspection.md)。

Mobile 复用[门店与模板管理](admin.md)和[日程方案与门店安排](schedules.md)的接口与规则：账号支持创建店长、改昵称、调店、停启和重置密码；门店支持创建、改名、停启和查看店长；模板支持检查项与 AI 配置、三套快捷配置；AI 标准支持增改删；日程支持七天任务与跨日时间窗，门店安排支持批量选方案和跳过日期区间。

表单适配手机屏幕，原生输入、选择和日期时间控件用于编辑；保存成功后更新列表，保存失败保留草稿。刷新不覆盖随后保存的新值。配置在重新打开应用后保留。管理端共享基础样式 token，未作页面视觉精修。

## 审核与看板

审核队列按任务显示待人工条目和当天已判定任务。任务详情展示条目照片、AI 理由、上传人、上传时间和当前结论；管理员可逐条判定或改判，结果刷新任务分数。今日视图显示各店任务、汇总、警告和待我处理项，不显示「AI 审核中」。总部看板支持周/月切换和门店、店长、日期趋势维度，展示完成率、逾期数、自检准确率及分数。

## 我的与通知

「我的」显示头像、昵称、登录名、角色和门店；登录名只读，管理员可编辑昵称。管理员与店长均可上传头像、改密码和退出。通知入口打开按未读、已读分组的收件箱，支持刷新、分页、跳转和标记已读；主页角标最多显示 `99+`，应用回到前台刷新未读数。通知规则见[站内通知](notifications.md)。
