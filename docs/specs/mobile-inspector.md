## 登录与今日巡检

店长使用登录名和密码登录；同一登录名可属于不同商家，登录凭据匹配多个商家账号时先选择商家。登录成功后使用系统 cookie 存储 HttpOnly `fw_session` 会话，不在 SecureStore 或 localStorage 保存凭据。登录后可在「我的」查看头像、昵称、登录名、角色和门店，上传本人头像、改密码或退出；登录名只读。重启应用后保持登录。管理员使用同一登录入口时进入 Mobile 管理端，店长不显示管理员入口。管理员可在登录页进入邮箱验证码找回密码；店长使用该入口时会被提示联系管理员重置密码。

账号被要求首次改密时，登录后先进入改密页；成功后进入今日巡检。闲置超过 7 天的会话失效；停用账号会立即吊销其会话。

请求失败时区分网络连接失败、读取照片失败和客户端请求未发出，并显示对应提示；开发态记录原始错误，不用 LogBox 红条遮挡界面。

未登录时只显示登录页，直接打开其他地址会回到登录页。登录后使用 Expo Router Tabs 底部栏切换「今日待巡」「记录」「通知」「我的」，个人资料固定在最右侧末项。只有「今日待巡」首页固定显示 Logo 与通知入口，标题、刷新和任务列表随正文滚动。任务详情是叠在 Tabs 上的独立页面，不显示底部栏；屏幕内返回入口和系统返回键均回到导航来源。通知打开任务后，其返回目标为通知收件箱。Expo Web 地址随页面切换：`/today`、`/records`、`/notifications`、`/profile`、`/inspection/:id`。

今日页显示当前门店当天的任务、模板名、时间窗和任务状态。跨零点的窗口显示「次日」；下拉刷新重新读取任务，没有任务时显示「今天没有巡检任务」。今日主操作优先进入第一项 `in_progress` 任务，没有进行中任务时进入第一项 `not_started` 任务，不选择 `overdue` 或 `submitted`；入口只使用 Today API 的现有 `status`，不在客户端按时间重算截止。没有可继续任务时显示「今日无可继续的任务」和「查看通知」，逾期或已提交任务仍留在列表中供查看。打回后截止后一小时宽限期内的任务在列表仍为 `overdue`，主入口不会指向该任务，需从打回通知进入详情。

点任务进入详情，按需读取检查项、验收要点、最低照片数、当前结论、最后提交人和上传时间；结论显示待审、通过、打回或不合格，不显示打回理由、自评、备注或存储信息。

任务开始前一小时起可上传。更早时显示可开始时间；截止后未上传项不可操作，打回项可在截止后一小时内重传，超过宽限期后不可操作。服务端拒绝时显示中文提示。每项的照片入口只调起系统相机，不提供相册选择；达到最低照片数后才能提交，零照片项须填写备注。需照片的条目须选择自评结果。任务图片之外，聊天图片仍可使用系统相册。

任务详情可查看[聊天面板](chat.md)。历史巡检详情仍只读显示各项判定、备注与照片；旧整单修改与补交入口已移除。

## 记录

「记录」Tab 显示当前门店的巡检，以及店长调店前参与过的原门店历史；同店内其他店长参与的记录也可见。按创建时间倒序排列，每行显示任务状态（无任务时显示巡检状态）、分数、模板名、任务日期、创建时间和提交时间。首屏 10 条，「加载更多」追加下一页，无更多时显示「没有更多了」；下拉刷新回到第一页，丢弃刷新前仍在途的旧页。加载、失败和空列表各有提示；网络、400/403/404 错误显示中文，401 返回登录。

点一行进入 `/records/:id`，展示结果、备注、照片、分数、状态和按时间排列的审核历史。检查项在任何状态都只读；任务处理在「今日待巡」进行。详情底部显示[聊天](chat.md)，按聊天权限收发。记录 API 仅店长可读；返回当前门店记录和本人参与过的历史记录，默认每页 10 条、最多 50 条，使用不透明游标，在同时间记录间以 ID 稳定排序。

## 通知

店长可从底部通知入口查看本人通知，角标显示未读数（最多显示 `99+`）。应用回到前台时刷新未读数；收件箱分未读和已读，支持下拉刷新、滚动加载更多，打开通知后跳转到对应任务、条目或聊天并标记已读。通知事件和权限见[站内通知](notifications.md)。

## 没有的

没有记录搜索、筛选或按日期跳转，列表不显示巡检人。任务照片只能从相机拍摄；聊天图片可从系统相册选择。
