# Mobile 店员巡检

代码（归档时再生成）：`apps/mobile/`

## 登录与今日巡检

店员使用邮箱和密码登录。登录后可在「我的」查看账号与门店并退出；重启应用后保持登录。登录用户只看到绑定门店的今日巡检，以及该店需要补交的巡检单。

新建巡检后，店员逐项选择合格或不合格、填写可选备注，并为必拍项上传照片。检查项未填写或必拍照片缺失时不能提交，页面指出待完成项。成功提交后显示 API 返回的状态与分数。

## 补交

打回单显示主管意见，并高亮最近一次打回记录中的检查项。店员可修改检查结果、补拍照片并重新提交；提交后显示 API 返回的新状态和分数。

## 没有的

没有「我的历史单」记录页，也不提供原生相机拍照的机器验收；用户可用 Expo Go 在真机完成相机和外观验收。
