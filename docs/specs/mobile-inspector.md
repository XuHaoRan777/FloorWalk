# Mobile 店员巡检

代码（归档时再生成）：`apps/mobile/`

## 登录与今日巡检

店员使用邮箱和密码登录。登录成功后使用系统 cookie 存储 HttpOnly `fw_session` 会话，不在 SecureStore 或 localStorage 保存凭据。登录后可在「我的」查看账号与门店并退出；重启应用后保持登录。登录用户只看到绑定门店的今日巡检，以及该店需要补交的巡检单。

请求失败时区分网络连接失败、读取照片失败和客户端请求未发出，并显示对应提示；开发态记录原始错误，不用 LogBox 红条遮挡界面。

未登录时只显示登录页，直接打开其他地址会回到登录页。登录后使用 Expo Router Tabs 底部栏切换「今日待巡」「记录」「我的」；巡检详情是叠在 Tabs 上的独立页面，不显示底部栏，在详情按 Android 返回键回到今日待巡。Expo Web 地址随页面切换：`/today`、`/records`、`/profile`、`/inspection/:id`。

新建巡检后，店员逐项选择合格或不合格、填写可选备注，并为必拍项上传照片。检查项未填写或必拍照片缺失时不能提交，页面指出待完成项。成功提交后显示 API 返回的状态与分数。门店停用后显示「门店已停用」且没有开始巡检按钮；历史仍可访问，重新启用后恢复入口，规则见[门店管理](admin.md#门店与停用)。

## 补交

打回单显示主管意见，并高亮最近一次打回记录中的检查项。店员可修改检查结果、补拍照片并重新提交；提交后显示 API 返回的新状态和分数。巡检页显示[聊天面板](chat.md)，可以收发文字和相册图片。

## 记录

「记录」Tab 显示本店全部状态的巡检，包含同店其他店员创建的单，按创建时间倒序排列。每行显示中文状态、分数（没有时为「—」）、创建时间和提交时间。首屏 10 条，「加载更多」追加下一页，无更多时显示「没有更多了」；下拉刷新回到第一页，丢弃刷新前仍在途的旧页。加载、失败和空列表各有提示；网络、400/403/404 错误显示中文，401 返回登录。

点一行进入 `/records/:id`，展示结果、备注、照片、分数、状态和按时间排列的审核历史。检查项在任何状态都只读，草稿和打回单的编辑走今日待巡。详情底部显示[聊天](chat.md)，按聊天权限收发。记录 API 仅本店店员可读；默认每页 10 条、最多 50 条，使用不透明游标，在同时间记录间以 ID 稳定排序。

## 没有的

没有记录搜索、筛选或按日期跳转，列表不显示巡检人；尚未提供原生相机入口，当前照片使用系统相册。
