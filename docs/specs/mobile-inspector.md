# Mobile 店员巡检

代码（归档时再生成）：`apps/mobile/`

## 登录与今日巡检

店员使用邮箱和密码登录。登录成功后使用系统 cookie 存储 HttpOnly `fw_session` 会话，不在 SecureStore 或 localStorage 保存凭据。登录后可在「我的」查看账号与门店并退出；重启应用后保持登录。登录用户只看到绑定门店的今日巡检，以及该店需要补交的巡检单。

请求失败时区分网络连接失败、读取照片失败和客户端请求未发出，并显示对应提示；开发态记录原始错误，不用 LogBox 红条遮挡界面。

未登录时只显示登录页，直接打开其他地址会回到登录页。登录后使用 Expo Router Tabs 底部栏切换「今日待巡」「我的」；巡检详情是叠在 Tabs 上的独立页面，不显示底部栏，在详情按 Android 返回键回到今日待巡。Expo Web 地址随页面切换：`/today`、`/profile`、`/inspection/:id`。

新建巡检后，店员逐项选择合格或不合格、填写可选备注，并为必拍项上传照片。检查项未填写或必拍照片缺失时不能提交，页面指出待完成项。成功提交后显示 API 返回的状态与分数。

## 补交

打回单显示主管意见，并高亮最近一次打回记录中的检查项。店员可修改检查结果、补拍照片并重新提交；提交后显示 API 返回的新状态和分数。

## 没有的

没有「我的历史单」记录页，也不提供原生相机拍照的机器验收；用户可用 Expo Go 在真机完成相机和外观验收。
