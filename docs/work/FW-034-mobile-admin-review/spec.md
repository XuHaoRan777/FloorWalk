# Mobile 管理端（二）：审核与看板

> ID：`FW-034`
>
> 状态：`approved`

## 目标

接力线二第 5 个。管理员在 Mobile 看审核队列、逐条判与改判、看今日视图和看板。功能等同 Web。

## 非目标

- 不接通知（FW-036/037）。
- 不改 API 语义，复用 FW-030、FW-031、FW-032 的接口。

## 验收标准

- AC-01（`用户要求`）：Mobile 审核队列：按任务分组显示待人工条目和今日已判定任务；点进看条目照片、AI 理由、上传人与"上传于 HH:mm"。
- AC-02（`用户要求`）：逐条判与改判：UI 控件适配手机；按 FW-028 的时间规则。改判结果同步到任务并实时刷新分数。
- AC-03（`用户要求`）：Mobile 今日视图：各店任务、汇总、警告、待我处理、分数；不显示"AI 审核中"。
- AC-04（`用户要求`）：Mobile 看板：周或月切换；完成率、逾期、自检准确率、分数；维度切换门店、店长、日期趋势。
- AC-05（`建议采纳`）：原生模拟器取证：造一组 AI 失败条目 → 在 Mobile 判通过 → 看板分数更新。截图写进 `evidence/`。
