# 个人中心（两端）

> ID：`FW-035`
>
> 状态：`approved`

## 目标

接力线二第 6 个。两端的"我的"页支持改头像、改密码；admin 还能改自己的昵称。头像走存储驱动（本地或 OSS）。

## 非目标

- 不做店长昵称的本人修改（基线禁止）。
- 不做邮箱、手机号修改（登录名不动）。
- 不做绑定其他商家、多账号切换（登录时已选）。

## 验收标准

- AC-01（`用户要求`）：`POST /api/me/avatar` 上传头像，返回新 storageKey；只接受 jpeg、png，≤2MB；旧头像在成功后清理（本地或 OSS）。
- AC-02（`用户要求`）：`PATCH /api/me`：admin 可改 `displayName`（1～30 字），店长改昵称返回 403。
- AC-03（`用户要求`）：改密码接口已存在，Web 和 Mobile 的"我的"页加入口；改密后吊销其他设备会话（沿用）。
- AC-04（`用户要求`）：Web 与 Mobile 的"我的"页：显示当前头像、昵称、登录名（只读）、角色、门店（店长）；admin 页有"昵称"编辑入口；两端都有"改头像""改密码""退出登录"。
- AC-05（`建议采纳`）：权限：跨商家 404；头像签名链接有效期沿用 1 小时。界面 e2e：改头像 → 刷新页面仍显示；改密码 → 其他端被登出。
