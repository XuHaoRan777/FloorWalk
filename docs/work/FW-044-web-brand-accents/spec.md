# Web 品牌与点缀

> ID：`FW-044`
>
> 状态：`approved`

## 目标

Web 管理员在认证页和控制台看到统一的巡检动线标志、认证主视觉和七处主空态插画，并可在审核详情页头查看已判定任务的分段圆环与分数。

## 非目标

- 本单不实现 Mobile 页面；Mobile 后续复用本单的 Logo 和插画。
- 工作区表格、表单、看板不增加持续运动或静态点缀。
- 不改变认证、审核、判定、任务状态和 API 语义。
- 账号空态保留现有「暂无账号」文案。通知抽屉、表格单元格、表单提示、局部列表空项、加载和错误均不配插画。
- 审核队列行、今日视图等沿用现有结果展示。D3 逾期反馈留给 Mobile。

## 验收标准

- AC-01（`用户要求`）：L1「F 字动线」以 `viewBox="0 0 32 32"` 绘制。路线为 `M9 25V8h15` 和 `M9 16.5h6`，描边宽 `3.4`、端点与转角为圆形；检查点圆心 `(20.5, 16.5)`、半径 `3.1`。路线使用 `--fw-primary`，检查点使用 `--fw-accent`。同一标志用于控制台侧栏、浏览器 favicon、登录和注册表单头；16px、32px、96px 显示及 favicon 实际尺寸均可辨认。
- AC-02（`用户要求`）：登录、注册、找回密码和改密码共用的 `AuthFrame` 使用 H5「平面 + 巡检单」主视觉和 C1 文案。标题为「门店巡检，逐条落实」，副文案为「按日程生成任务，店长现场拍照，AI 逐条审核」。主视觉背景使用品牌蓝；平面仅使用半透明白色细线，不标房间名。路线经过检查点时巡检单逐项点亮勾选，动画只播放一次并停在终态。巡检单只呈现无文本的抽象行与勾选状态，不出现门店、时间、数量或其他业务数据。
- AC-03（`用户要求`）：H5 SVG 画板为 `640×520`。平面坐标位于 `<g transform="translate(56 92) scale(.86)">` 内。外框路径为 `M290 410H70V60h500v350H350`。室内元素为 `rect(x=100,y=90,width=150,height=56,rx=4)`、`rect(x=300,y=100,width=230,height=20,rx=3)`、`rect(x=300,y=170,width=230,height=20,rx=3)`、`rect(x=300,y=240,width=160,height=20,rx=3)`、`rect(x=482,y=296,width=62,height=88,rx=4)` 和路径 `M70 290h150v120`。平面描边宽 `1.7`，颜色为 `color-mix(in srgb, var(--fw-card) 22%, transparent)`。路线为 `M320 440V370h-50V144h275v70H300v86h160v40`，描边宽 `3.5`、颜色为 `--fw-card`、圆头圆角。检查点坐标及路线进度依次为 `(320,370,.057)`、`(270,165,.266)`、`(420,144,.406)`、`(420,214,.668)`、`(460,340,1)`。每经过一个检查点，右下角巡检单的五行同步点亮一枚勾。巡检单宽 `228px`，只显示无文字和数值的抽象行，不显示班次、检查项名称、张数或业务数据。背景使用 `--fw-primary`，点阵使用 `24×24` 周期、半径 `1.2` 的圆点，颜色为 `color-mix(in srgb, var(--fw-card) 20%, transparent)`。其余颜色只引用 token，派生色使用 `color-mix()`。
- AC-04（`用户要求`）：三张 E1 插画静态绘制并按本节映射到七个主空态。画板均为 `160×120`。主要位置锚点、路线节点和块面中心线落在 `4px` 网格上；框线宽 `1.5`、圆角 `6`；块面使用 `--fw-muted` 且不描边。路线圆点使用 `2px` 圆头描边和 `stroke-dasharray="0 6"`，相邻圆点边缘净距 `4px`；空心检查点半径 `4.5`。外框描边用 `--fw-input`，路线及空心检查点描边用 `color-mix(in srgb, var(--fw-muted-foreground) 50%, var(--fw-card))`，点阵用 `--fw-input`，通知图光晕用 `--fw-raised`。空态原有触发条件、文案和操作按钮保持不变，只增加对应插画。账号空态不配插画，保留现有文案。
- AC-05（`用户要求`）：审核详情页头常驻显示 R2 圆环。圆环使用 `180×180` SVG 画板，中心 `(90,90)`、半径 `74`、描边宽 `10`，轨道使用 `--fw-muted`。检查项按列表顺序从顶部顺时针等分。圆心和弧段同步显示当前得分与逐项结论。待判和仍属系统缺交的条目留空轨道。缺交项改判通过后用 `--fw-primary` 蓝弧，之后改判不合格用 `--fw-destructive` 红弧；详情保留截止时缺交的历史记录。当前通过项用蓝弧，当前不合格项用红弧。12 条及以下时，圆头线帽扣除后的可见段间空隙为 `10°`，路径中心线端点按半线宽与半径补偿内缩；超过 12 条时取消间隔，沿圆周合并相邻同色弧段，保留未完成项所在的空轨道。圆环中心显示服务端 `task.score`，分数为空时显示 `—`。闭合处显示整单结论徽标。整单通过使用青绿底白色勾，整单不通过使用红底白色叹号。徽标、条目列表和结论标签沿用语义色。审核详情契约以 `manuallyDecidedAfterCompletion` 区分缺交后的人工改判与仍属系统缺交的状态。
- AC-06（`用户要求`）：本单品牌动效只使用「描画」和「点亮」。R2 沿弧段描画，徽标在闭合处原地从 `0.6` 缩放至 `1`，约 `0.3s`，全程位置固定。仅整单通过在播放时短暂显示外扩光圈。`prefers-reduced-motion: reduce` 下直接呈现终态。颜色取自 `packages/tokens/tokens.css`，派生色用 `color-mix()`。确需新增 token 时须能指向本单 AC。
- AC-07（`用户要求`）：归档时在 `docs/context/design.md` 新增「品牌与点缀」小节，记录本单已批准且已落地的 Logo、H5、E1、R2、动效和颜色规则。
- AC-08（`用户要求`）：审核详情页头始终以 R2 显示当前检查项结果和分数，分数为空时中心沿用 `—`。打开或刷新已判定任务时直接显示静态终态。只有当前管理员在该详情页判定成功，且操作前的 `decidedAt` 为空、成功响应中的 `decidedAt` 有值，或者在该详情页改判成功时，才播放一次对应结果。未产生整单判定的判定操作只静态更新圆环。播放期间再次改判，收到成功响应后取消当前播放并直接切到最新终态，不再启动新播放，该次不排队、不叠加。播放结束后的圆环和分数保持终态。
- AC-09（`用户要求`）：侧栏账户菜单打开后，点击菜单之外的页面区域或按 Escape 会关闭菜单；按 Escape 关闭后焦点返回账户菜单触发器。功能页通用次级按钮、任务查看入口和信息提示等非结果语义强调使用品牌蓝；青绿色用于检查点和成功语义。

## E1 插画

矩形坐标按 `(x, y, 宽, 高)` 记录。

- 「今日任务」用于今日视图无任务、总部看板当前周期无数据。外框路径为 `M72 104H30a6 6 0 0 1-6-6V22a6 6 0 0 1 6-6h100a6 6 0 0 1 6 6v76a6 6 0 0 1-6 6H88`。左侧块面为 `(36,28,32,12,rx=3)`。右侧三行块面分别为 `(84,28,40,6,rx=3)`、`(84,44,40,6,rx=3)`、`(84,60,40,6,rx=3)`。未点亮路线为 `M80 116V84M112 84H48V56`，空心检查点中心为 `(48,56)`、`(80,84)`、`(112,84)`。
- 「模板」用于门店、模板、AI 审核标准和日程方案列表为空。清单外框为 `rect(x=40,y=12,width=80,height=96,rx=6)`，路线为 `M56 32V92`。前三个空心检查点中心为 `(56,32)`、`(56,52)`、`(56,72)`；右侧块面为 `(68,29,40,6,rx=3)`、`(68,49,32,6,rx=3)`、`(68,69,36,6,rx=3)`。末端是圆心 `(56,92)`、半径 `7` 的 `--fw-primary` 圆形加号，横竖白线宽 `1.6`；右侧末行块面为 `(68,89,28,6,rx=3)` 并使用 `--fw-raised`。
- 「通知」用于审核队列总览为空，即待人工和今日已判定均为空。外框为 `rect(x=24,y=16,width=112,height=88,rx=6)`。普通点半径 `1.75`，按 `16px` 间距排列于 `x=40…120`、`y=36…84`，略去 `(88,52)`；该位置用半径 `10` 的 `--fw-raised` 圆衬底和半径 `4` 的 `--fw-primary` 亮点替代。
