# 模板与 AI 审核标准

> ID：`FW-026`
>
> 状态：`approved`

## 目标

接力线一第 3 个。商家可以有多个模板，检查项改为标题、严重项、最少照片张数、验收要点；AI 审核标准成为独立的库，模板选用一份并可关闭 AI；三套快捷配置一键生成可用的模板和标准。API 与 Web。

## 非目标

- 不做 AI 审核执行（线二）；本单元只存配置。
- 不做日程（FW-027）；模板"用在哪"由日程决定，本单元不再有"当前模板"。
- 不做模板删除、编辑冲突检测。

## 验收标准

- AC-01（`用户要求`）：去掉"当前模板"概念（`is_current`、设当前接口、Web 标记），一个商家最多 20 个模板，第 21 个 409。现有今日巡检在 FW-028 前的过渡：店长建单时可选本商家任一模板（FW-028 改为按任务）。
- AC-02（`用户要求`）：检查项字段为标题、是否严重项、最少照片张数（0～10 的整数，0 表示不拍）、验收要点（0～500 字）；去掉"是否必拍"。最少张数为 0 的项，提交时备注必填；张数大于 0 的项，提交时照片数不少于最少张数。巡检单快照复制这些字段，改模板不影响已有单。
- AC-03（`用户要求`）：AI 审核标准库：admin 增改查，每份是名称（商家内唯一）加提示词（1～4000 字）；被模板引用的标准不能删除（409）。
- AC-04（`用户要求`）：模板上有"启用 AI"开关（默认开）和所选标准；开启时必须选一份本商家的标准，否则 400；关闭时可以不选。
- AC-05（`用户要求`）：快捷配置：Web 模板页提供咖啡店、餐馆、花店三个按钮，点击后在服务端生成一个模板（含检查项、验收要点、至少一个严重项）和一份 AI 审核标准并选中；同名已存在时自动加序号，不报错。
- AC-06（`建议采纳`）：模板、标准接口只允许 admin，店长 403；跨商家 404。
- AC-07（`用户要求`）：Web 模板页按新字段编辑；AI 标准页可增改；界面 e2e 覆盖：点快捷配置"咖啡店" → 看到新模板与标准 → 改一项最少张数并保存 → 刷新后保留。
