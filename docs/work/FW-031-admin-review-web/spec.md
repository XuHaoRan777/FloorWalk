# 管理员审核与改判（Web）

> ID：`FW-031`
>
> 状态：`approved`

## 目标

接力线二第 2 个。管理员在 Web 看审核队列：AI 失败转人工的条目、关闭 AI 的模板的待判条目、以及已判定后想改判的任务。可以逐条判与改判，并看到"待我处理"数量。

## 非目标

- 不做看板（FW-032）、Mobile 管理端（FW-033、FW-034）。
- 不做通知（FW-036），改判通知留给那边。

## 验收标准

- AC-01（`用户要求`）：审核队列 Web 页：列出"待人工"的条目（按任务分组，显示门店、模板、提交时间、理由），以及"今天已判定"的任务供改判；admin 点进任务看逐条上传人、"上传于 HH:mm"、照片、AI 理由、当前结论。
- AC-02（`用户要求`）：逐条判：通过、打回（附理由）、不合格；按 FW-028 的时间规则（截止后 1 小时后不能打回，只能判通过或不合格）。改判：判定后 admin 可改任一条结论；每次改判记录操作人、时间、原结论、新结论。响应给出重算的分数与整单结论。
- AC-03（`建议采纳`）：队列只允许 admin；跨商家 404。界面 e2e 覆盖：假模型失败 → 条目入"待人工" → admin 判通过 → 任务进入已判定 → 改判一条 → 分数变化。
- AC-04（`建议采纳`）："待我处理"计数在 Web 顶栏实时可见，10 秒轮询或页面聚焦刷新。
