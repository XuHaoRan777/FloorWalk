# Mobile 管理端（一）：配置

> ID：`FW-033`
>
> 状态：`approved`

## 目标

接力线二第 4 个。管理员在 Mobile 原生 App 里完成配置：账号、门店、模板与 AI 标准、日程。功能等同 Web，表单适配手机屏。

## 非目标

- 不做 Mobile 的审核、改判、今日视图、看板（FW-034）。
- 不做店长 Mobile 的改动（FW-029 完成）。
- 不接相机、无文件选择器需求；头像与图片由 FW-035 的个人中心处理。

## 验收标准

- AC-01（`用户要求`）：登录后 admin 看到"管理员主页"：入口为账号、门店、模板、AI 标准、日程、门店日程安排。店长登录不看到这些入口。
- AC-02（`用户要求`）：账号页：列表、建店长、改昵称与门店、停用与启用、重置密码（走共用接口）。
- AC-03（`用户要求`）：门店页：建、停用与启用、改名、看每店店长列表（去指派主管）。
- AC-04（`用户要求`）：模板页：新建、编辑检查项、开关 AI 与选 AI 标准、快捷配置三套（点一下即生成）。
- AC-05（`用户要求`）：AI 标准页：列表、新建、改、删（被引用时拦截）。
- AC-06（`用户要求`）：日程方案页 + 门店日程安排页：按天编辑任务列表（时间窗、跨零点）；多选门店批量设置方案和跳过日期区间。
- AC-07（`建议采纳`）：原生模拟器取证：Android 模拟器走通建店长 → 建模板（含快捷配置） → 建方案 → 给门店选用方案 → 加一个跳过区间 → 刷新保留。截图写进 `evidence/`（不入库）。
