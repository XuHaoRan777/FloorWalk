# 日程方案与门店日程安排

> ID：`FW-027`
>
> 状态：`approved`

## 目标

接力线一第 4 个。管理员建多份以周为循环的日程方案，每天是"模板 + 时间窗"的任务列表；在「门店日程安排」页给门店选用方案、批量设置跳过日期区间。本单元只存配置并能算出"某店某天应有哪些任务"，不生成任务实例。API 与 Web。

## 非目标

- 不生成任务实例、不做状态与逾期（FW-028）。
- 不做临时任务、排班。

## 验收标准

- AC-01（`用户要求`）：日程方案 admin 增改查；名称商家内唯一；每个方案有周一到周日 7 天，新建时 7 天全部启用；每天是任务列表，任务是模板（本商家）+ 开始时刻 + 结束时刻（分钟精度）。结束早于或等于开始表示跨零点，时长 1 分钟～24 小时；任务数不设上限；时间窗可以重叠，同一模板一天可以出现多次。停用某一天表示这天不排任务。
- AC-02（`用户要求`）：门店日程安排：每家门店选用 0 或 1 份方案；可以一次给多家门店设同一个方案。
- AC-03（`用户要求`）：跳过日期：一次给一家或多家门店添加一个日期区间（起止日期含两端，可以只有一天）和可选备注；可以删除；区间重叠允许。
- AC-04（`用户要求`）：提供纯函数（共享契约）`planFor(site, date)`：按商家时区，给出该门店该日应有的任务列表（模板、窗口开始与结束的绝对时间）。跨零点的任务算在开始那天；跳过日期内、方案该天停用、门店停用或未选方案时为空。单元测试覆盖跨零点、跳过区间边界、时区。
- AC-05（`建议采纳`）：被方案引用的模板不能删除或被改到别的商家；方案被门店选用时可以修改，不能删除（409）。admin 以外 403，跨商家 404。
- AC-06（`用户要求`）：Web「日程方案」页按天编辑任务列表；「门店日程安排」页列出门店、所选方案、跳过区间，支持多选门店批量操作。界面 e2e 覆盖：建方案（含一个跨零点任务）→ 给两家店选用 → 给其中一家加跳过区间 → 刷新后保留。
