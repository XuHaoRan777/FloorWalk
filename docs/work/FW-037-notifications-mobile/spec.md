# 站内通知（Mobile 收件箱与角标）

> ID：`FW-037`
>
> 状态：`approved`

## 目标

接力线二第 8 个。Mobile 两端（店长端、管理端）加通知入口、收件箱页、未读角标；点一条跳对应页面。

## 非目标

- 不做远程推送、Expo Push（基线明确不做）。
- 不做桌面端通知。
- 不改通知后端接口（FW-036 完成）。

## 验收标准

- AC-01（`用户要求`）：底部 tab 或顶栏显示未读数（≤99 显示数字、>99 显示 "99+"）；应用从前台返回时刷新一次；App 内切页不频繁拉。
- AC-02（`用户要求`）：收件箱页：列未读、已读分组；下拉刷新、滚动到底加载更多；点一条跳转对应页面并标已读（店长巡检任务、管理端审核队列、聊天页）。
- AC-03（`用户要求`）：权限：跨商家不显示；账号被停用后 App 下次启动登出。
- AC-04（`建议采纳`）：原生模拟器取证：造一条"打回"通知 → Mobile 店长端看到未读 1 → 打开跳到对应条目 → 未读清零。截图写进 `evidence/`（不入库）。
