# Mobile 管理员主路径页面还原

> ID：`FW-048`
>
> 状态：`approved`

## 目标

将 Mobile 管理员的今日、审核队列、审核详情、看板、通知和我的 6 个页面按已确认设计稿还原到 `apps/mobile`。页面使用 FW-047 已建立的视觉基线、样式变量、字体与公共组件。

## 非目标

- 不改接口、取数、权限、服务端规则、共享类型或业务提交语义。
- 不改 Web、`packages/tokens`、Logo，不重做 FW-047 视觉基础。
- 不实现设计稿中当前接口没有的数据，不复制图库照片到应用、测试数据或证据。
- 不操作模拟器，不新增行为测试。
