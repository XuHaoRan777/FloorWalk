# AI 真模型验收与提示词调优

> ID：`FW-038`
>
> 状态：`approved`

## 目标

接力线二线尾。把 AI 审核从假模型切到真模型（OpenAI 兼容接口），用演示数据和真实样本照片走一遍，调审核提示词让判断稳定；同时顺带检查基线里标「AI 定」的条目，有不合适就在本单元或 testlog 里记录。

## 非目标

- 不改状态机、不改 API 语义（必要时发现问题通过回修或 testlog）。
- 不做模型供应商选型：按用户配置的 `OPENAI_BASE_URL` 走，Agent 不发真请求。

## 验收标准

- AC-01（`用户要求`）：切到真模型后，Agent 在本地跑 `AI_REVIEW_DRIVER=openai` 的烟雾测试，覆盖一张合格、一张不合格、一张模糊证据；输出结论和理由、延迟和 token 数写进 `evidence/`。
- AC-02（`用户要求`）：由用户亲自跑一遍端到端：注册 → 建店长 → 建模板（开 AI）→ 配置日程 → 等任务生成 → 店长上传几条 → 看 AI 结论是否合理 → 判定与改判 → 看板出数。交接两行后用户确认即归档。
- AC-03（`用户要求`）：对基线里"AI 定"的 17 条顺带检查，异常写进 plan「决策与偏差」或开 testlog 行；没有异常就记一行"均符合预期"。
- AC-04（`建议采纳`）：如果提示词需要迭代，在本单元内修改模板里的 AI 标准与 AI 适配器的拼装；每次迭代留一个样本输出记录。
