# 真实邮件验收

> ID：`FW-039`
>
> 状态：`approved`

## 目标

把 API 切到 Resend 驱动，用真实邮箱走一遍注册验证和管理员找回密码，确认验证码邮件能收到、内容可读、流程走得通。不接力，单独一个会话。

## 非目标

- 不改验证码规则（5 分钟过期、60 秒重发、输错 5 次作废，FW-025 已取证）。
- 不改邮件模板内容和发件域名的 DNS；发现问题记进「交接」，另开修正。
- 不做店长找回密码、短信、通知邮件。

## 验收标准

- AC-01（`用户要求`）：用户把本机 `apps/api/.env.development` 的 `MAIL_DRIVER` 改为 `resend`，填好 `RESEND_API_KEY`；Agent 只核对键存在、不读取值，`python scripts/validate_docs.py --env-keys` 不报缺键，API 能启动。
- AC-02（`用户要求`）：Agent 用一个用户提供的收件邮箱请求一次注册验证码，记录 API 响应和 Resend 返回的消息 ID（不记验证码），确认请求成功。真实发信最多 5 封。
- AC-03（`用户要求`）：用户在 Web 上用真实邮箱完成注册：收到验证码邮件，主题和正文能看懂，验证码有效期写"5 分钟"，注册成功进入控制台。
- AC-04（`用户要求`）：用户用同一邮箱走一遍"忘记密码"：收到验证码，验证后设新密码，用新密码能登录，旧会话失效。
- AC-05（`建议采纳`）：收尾时把 `MAIL_DRIVER` 改回 `fake`，或由用户确认保留 `resend`；停掉本单元起的 API 和 Web 进程。

## 验收方式

`A 人工验收`

真实外部服务，只有用户能看到收件箱。Agent 做 AC-01、AC-02 和 AC-05，交接两行后由用户完成 AC-03、AC-04。
