# 今日视图与看板（Web）

> ID：`FW-032`
>
> 状态：`approved`

## 目标

接力线二第 3 个。管理员在 Web 看今日视图（各店任务、汇总、警告、待我处理、分数）和看板（完成率、逾期、自检准确率、分数，按周或月，按门店、店长、日期趋势）。

## 非目标

- 不做 Mobile 管理端（FW-034）。
- 不做 Excel 导出、PDF 报表。
- 不做可自定义维度；基线三个维度固定。

## 验收标准

- AC-01（`用户要求`）：今日视图 Web 页：各店今日任务列表（门店、模板、时间窗、状态、分数）；今日汇总卡（应完成、已完成、逾期）；警告区（严重项不合格的任务、逾期任务）；"待我处理"区（AI 失败转人工、关闭 AI 的模板待审）。不显示"AI 审核中"。
- AC-02（`用户要求`）：看板 Web 页：周粒度（本周），可切到月；完成率 = 截止前交齐的任务 ÷ 应完成的任务；逾期数；自检准确率（取 FW-030 的接口）；分数平均（judged 单）。
- AC-03（`用户要求`）：维度切换：门店（默认）、店长（排行榜，列出提交条目数、通过率、自检准确率）、日期趋势（折线）。
- AC-04（`建议采纳`）：admin 只读本商家数据；跨商家 404。界面 e2e 覆盖：造一批判定过的任务 → 看板分数与完成率符合预期 → 切换月粒度 → 切换店长维度。
- AC-05（`建议采纳`）：空数据状态：没任何任务时"今日无任务"、看板给"本周暂无数据"，不显示空图表。
