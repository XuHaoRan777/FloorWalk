# 操作步骤

两类内容，都是"到了那个时机才读、不读会做错"的步骤；规则本身在 [`AGENTS.md`](../../AGENTS.md)。

## 工作流步骤（随模板提供，触发写在内核对应节）

- [开单元](open-unit.md)：讨论新单元，写、批准 `spec.md` 与 `plan.md`，给开工提示词时读（第 5 节）
- [最终代码审查](final-review.md)：派审查、回修补审、修正合审时读（第 9、10 节）
- [单元收尾与归档](archive.md)：单元 `verified|descoped` 后读（第 11 节）
- [修正模式收尾](fix-promote.md)：用户说"收一下"时读（第 3 节）
- [自动接力](relay.md)：单元带「接力」，或批准一条接力线时读（第 6 节）
- [并行组](parallel.md)：单元带「并行组」，或开、并、收一组时读（第 6 节）
