# 0001. 新仓库做门店巡检，不续作 CardFlow

- 状态：`accepted`
- 日期：`2026-09-18`
- 来源工作单元：`-`
- 取代：`-`

## 背景

`F:\react_project\Gift2CashApp`（CardFlow）是未上架的礼品卡兑现系统，不适合作为作品展示。可复用的是证据采集、人工审核、提交时快照和三端形态，不是兑卡与资金盘。

## 决策

- 新产品新仓库 FloorWalk，旧仓库只读参考，不改名续作。
- 垂直切口为连锁门店巡店，演示租户 Northbean Coffee。
- 不碰支付、提现、礼品卡、可兑付积分。
- 有代码时按模块移植基础设施，不整仓 clone 再抽杀。
- 领域对象新表新文件，不用 `GiftCard*` 改字段名。

## 后果

实现从空壳开始。旧项目的聊天、上传、审核队列只能当模式参考。对外叙事不再出现 CardFlow / gift card / 积分提现。

## 被否决的方案及原因

- 在 CardFlow 上改皮：作品仍像灰产金融。
- 电子卡密改成「数字资产 / voucher」：同一条变现管道。
- 万能巡检平台或工业物联网：超出一人可交付范围，也和现有「拍照 + 审单」不匹配。
- 整仓拷贝再删礼品卡：残渣（Points、Naira、FakeRanking）很容易留下。
